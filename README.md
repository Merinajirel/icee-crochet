An online crochet store developed as an academic e-commerce project.

Icee Crochet is a web-based e-commerce platform designed to showcase and sell handmade crochet products. It provides customers with a simple shopping experience and allows administrators to manage products and orders.

Features
- User registration and login
- Product browsing
- Shopping cart functionality
- Order placement and management
- Admin dashboard
- Product and stock management
- Customer reviews and ratings
- eSewa and Khalti payment gateway integration

Technologies used
- html, css, javascript
- php, mysql, xampp
